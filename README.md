# 지킴노트

말씀을 지키는 노트 — 성경 구절을 쓰면 말씀이 자동으로 들어가는 메모 앱 (안드로이드·아이폰 웹앱 · PWA)

주소: https://eleven.me.kr/BibleNote/ (GitHub 계정의 사용자 지정 도메인. 예전 주소 https://rikka7061.github.io/BibleNote/ 는 이리로 넘어온다. 저장소 이름은 BibleNote 그대로)

```
요한복음1:12 ␣   →   요한복음1:12 (영접하는 자 곧 그 이름을 믿는 자들에게는 하나님의 자녀가 되는 권세를 주셨으니)
```

## AI 노트 (주제 탭 · 용어 자동 입력)

- 노트 화면 위쪽 탭: **말씀**(기본) + 직접 만드는 탭(예: 미시경제학) + **＋ 탭 만들기**
- 탭마다 **규칙 · 참고 자료**(책·논문, "한 문장으로" 같은 규칙)와 **용어 사전**을 적어 둔다 (`js/subjects.js`)
- 노트에 `상품수지:`처럼 용어 뒤에 콜론을 치면 `상품수지: (상품의 수출과 수입의 차액을 나타내는 수지.)`
  1. 그 탭의 용어 사전에 있으면 바로 넣음
  2. 없으면 **Claude**가 탭의 규칙·참고 자료를 따라 한 문장으로 써서 넣고, 사전에 저장 (다음부터는 무료) (`js/ai.js`)
  3. AI를 연결하지 않았으면 아래에 **뜻 추가** 카드 → 적어 두면 사전에 저장
  - `참고:` `날짜:` 같은 머리말, `3:30` 같은 시각은 건드리지 않음. 콜론 앞 문장에서 사전에 있는 용어를 먼저 찾고, 없으면 짧은 줄 전체나 마지막 낱말을 용어로 본다
- **말씀** 탭: 성경 구절 자동 입력 그대로 + `독생자:` → 성경 단어 풀이 사전
- 용어 사전은 '용어: 뜻' 줄들을 한꺼번에 붙여넣어 채울 수 있다 (`용어 - 뜻`, `용어 = 뜻`, 탭으로 나눈 줄도 됨)
- **AI 연결**: 설정 → AI 연결에 본인의 Claude API 키(console.anthropic.com). 키는 기기 localStorage에만, 동기화 안 함
  - 공식 SDK `@anthropic-ai/sdk`를 AI를 처음 쓸 때 CDN에서 불러옴 (`dangerouslyAllowBrowser: true` — 본인 키를 본인 기기에서만 쓰므로)
  - 모델: 기본 Claude Opus 5.5 (`effort: low`, 거절 시 서버 측 fallbacks), 설정에서 Claude Haiku 5.5로 바꿀 수 있음

## 기능

- 일반 메모앱처럼 메모 목록 · 제목 · 내용, 자동 저장, 검색
- 구절을 쓰고 **띄어쓰기/줄바꿈** → 괄호 안에 말씀 자동 입력 (알림에서 되돌리기 가능)
  - `요한복음 1:12` `요 1:12` `요 3:16-18` `롬 8:28~30` `요 3:16,18` `창 1:31-2:3`
  - `요한복음 1장 12절` `시편 23편 1-6절`
  - 책 이름은 정식 이름으로 바꿔 줌: `요1:14` → `요한복음1:14`, 오타도 교정 `애레미야` → `예레미야` (자모 비교, `js/hangul.js`)
- 이미 써 둔 구절을 누르면 아래에 **말씀 넣기** 버튼
- 앞에 `요 3:1-13`을 써 두면 나중에 `3절`만 써도 요한복음 3:3을 찾아 카드로 보여 줌 (넣기)
- **문구로 말씀 찾기(역추적)**: `하나님께서 세상을 사랑하사` → 아래에 `요한복음 3:16 · 바꾸기` 제안
  - 줄 전체가 확실히 한 절이면 줄바꿈할 때 바로 `요한복음 3:16 (말씀)`으로 바뀜 (되돌리기 가능)
  - 조사·어미가 달라도, 중간 단어를 빼먹어도 찾음 (`js/search-worker.js`, 별도 스레드)
- **말씀 찾기**: 구절을 검색해서 미리 보고 메모에 넣기 (어려운 단어 풀이 함께)
- **어려운 단어 풀이** (`js/glossary.js`): 넣어 둔 말씀(괄호 안)에서 옛말·성경 용어·단위·지명 약 230개를 찾아 뜻을 보여 줌
- **펜 필기** (`js/ink.js`): 글 위에 동그라미·밑줄, 여백에 그림. 선은 글자 위치에 붙어서 위에 글을 더 써도 같이 내려감. S펜이면 펜으로 쓰고 손가락으로 스크롤
- **기호 자동 변환**: `->` → `→`, `<-` ←, `<->` ↔, `=>` ⇒, `!=` ≠, `>=` ≥, `<=` ≤ (바로 지우면 원래 글자로)
- **글자 크기** 4단계
- **글자 서식** (`js/marks.js`): 글자를 선택하면 굵게 · 빨강 · 파랑 · 형광펜. 입력창은 그대로 두고 뒤쪽 층에 서식을 그린다 (입력창 글자는 투명, 굵게는 폭이 안 바뀌는 외곽선)
- **성경 탭** (`js/bible-tab.js`): 앱에 든 개역한글로 읽기·찾기(구절/문구), 절을 골라 복사·단어 풀이·메모에 넣기. **갓피아** 버튼은 보고 있던 장을 개역개정으로 연다 (설정에서 탭 누를 때 자동으로 열기 가능)
- **악보 탭** (`js/score-tab.js`): 찬양 제목·가사·찬송가 장으로 악보 이미지 검색(Google·네이버)과 가사 검색으로 바로 연결. 악보는 저작권이 있어 앱에 담지 않는다
- 인터넷 없이도 동작 (성경 본문이 앱 안에 들어 있음)
- 홈 화면에 설치 가능, 다크 모드, 공유(카톡 등), 백업 파일 저장/불러오기
- **Google 로그인 동기화**: 휴대폰·PC 어디서나 같은 메모 (설정 → Google 로그인)

## 동기화 (Firebase)

- 프로젝트 `biblenote-3ef1e` (무료 Spark 요금제, 카드 등록 없음 → 요금이 나갈 수 없음)
- Google 로그인(Firebase Auth) + 저장(Firestore, 서울 리전): `users/{uid}/notes/{id}` (`tab` = AI 노트 주제 탭 id, 말씀 탭이면 없음; `ink` 필드에 JSON 글자로: 필기만 있으면 배열, 글자 서식도 있으면 `{ s: 필기, m: 서식 }`)
- `users/{uid}/subjects/{id}`: 주제 탭 (`name`, `rules`, `auto`, `dict` = 용어 사전 JSON 글자)
- 아이폰은 팝업 로그인이 막혀서, 구글 로그인 페이지로 갔다 돌아오는 방식 (Google Cloud 웹 클라이언트에 리디렉션 주소 등록 필요)
- 보안 규칙 `firestore.rules`: 본인 메모만 읽기/쓰기. 바꾸면 Firebase 콘솔 → Firestore → 규칙에 붙여넣고 게시
- 오프라인에서도 기기에 먼저 저장되고, 연결되면 마지막 수정 시각이 최신인 쪽으로 맞춘다
- 삭제한 메모는 다른 기기에도 전달되도록 내용 없이 `deleted` 표시만 남긴다
- 로그인 안 하면 Firebase를 아예 불러오지 않는다
- 새 도메인에서 쓰려면 Firebase 콘솔 → Authentication → 설정 → 승인된 도메인에 추가하고, 아이폰 로그인용으로 Google Cloud → Google 인증 플랫폼 → 클라이언트(웹)에 JavaScript 원본·리디렉션 URI(`https://도메인/BibleNote/`)를 추가

## 휴대폰에 설치

HTTPS 주소가 있어야 설치·오프라인이 됩니다. 가장 쉬운 방법은 GitHub Pages:

1. GitHub에 저장소를 만들고 이 폴더의 파일을 올린다 (`tools/ko_krv_source.json` 제외)
2. 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장
3. 휴대폰 크롬에서 `https://<아이디>.github.io/<저장소>/` 열기 → 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**
