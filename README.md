# 지킴노트

말씀을 지키는 노트 — 성경 구절을 쓰면 말씀이 자동으로 들어가는 메모 앱 (안드로이드·아이폰 웹앱 · PWA)

주소: https://rikka7061.github.io/BibleNote/ (저장소 이름은 설치된 앱이 깨지지 않도록 BibleNote 그대로 둔다)

```
요한복음1:12 ␣   →   요한복음1:12 (영접하는 자 곧 그 이름을 믿는 자들에게는 하나님의 자녀가 되는 권세를 주셨으니)
```

## 기능

- 일반 메모앱처럼 메모 목록 · 제목 · 내용, 자동 저장, 검색
- 구절을 쓰고 **띄어쓰기/줄바꿈** → 괄호 안에 말씀 자동 입력 (알림에서 되돌리기 가능)
  - `요한복음 1:12` `요 1:12` `요 3:16-18` `롬 8:28~30` `요 3:16,18` `창 1:31-2:3`
  - `요한복음 1장 12절` `시편 23편 1-6절`
  - 책 이름은 정식 이름으로 바꿔 줌: `요1:14` → `요한복음1:14`, 오타도 교정 `애레미야` → `예레미야` (자모 비교, `js/hangul.js`)
- 이미 써 둔 구절을 누르면 아래에 **말씀 넣기** 버튼
- 앞에 `요 3:1-13`을 써 두면 나중에 `3절`만 써도 요한복음 3:3을 찾아 카드로 보여 줌 (넣기)
- **문구로 말씀 찾기(역추적)**: `하나님께서 세상을 사랑하사` → 아래에 `요한복음 3:16 · 바꾸기` 제안
  - 줄 전체가 확실히 한 절이면 줄바꿈할 때 바로 `요한복음 3:16 (말씀)`으로 바뀜 (되돌리기 가능)
  - 조사·어미가 달라도, 중간 단어를 빼먹어도 찾음 (`js/search-worker.js`, 별도 스레드)
- **말씀 찾기**: 구절을 검색해서 미리 보고 메모에 넣기 (어려운 단어 풀이 함께)
- **어려운 단어 풀이** (`js/glossary.js`): 넣어 둔 말씀(괄호 안)에서 옛말·성경 용어·단위·지명 약 230개를 찾아 뜻을 보여 줌
- **펜 필기** (`js/ink.js`): 글 위에 동그라미·밑줄, 여백에 그림. 선은 글자 위치에 붙어서 위에 글을 더 써도 같이 내려감. S펜이면 펜으로 쓰고 손가락으로 스크롤
- **기호 자동 변환**: `->` → `→`, `<-` ←, `<->` ↔, `=>` ⇒, `!=` ≠, `>=` ≥, `<=` ≤ (바로 지우면 원래 글자로)
- **글자 크기** 4단계
- 인터넷 없이도 동작 (성경 본문이 앱 안에 들어 있음)
- 홈 화면에 설치 가능, 다크 모드, 공유(카톡 등), 백업 파일 저장/불러오기
- **Google 로그인 동기화**: 휴대폰·PC 어디서나 같은 메모 (설정 → Google 로그인)

## 동기화 (Firebase)

- 프로젝트 `biblenote-3ef1e` (무료 Spark 요금제, 카드 등록 없음 → 요금이 나갈 수 없음)
- Google 로그인(Firebase Auth) + 저장(Firestore, 서울 리전): `users/{uid}/notes/{id}` (펜 필기는 `ink` 필드에 JSON 글자로)
- 아이폰은 팝업 로그인이 막혀서, 구글 로그인 페이지로 갔다 돌아오는 방식 (Google Cloud 웹 클라이언트에 리디렉션 주소 등록 필요)
- 보안 규칙 `firestore.rules`: 본인 메모만 읽기/쓰기. 바꾸면 Firebase 콘솔 → Firestore → 규칙에 붙여넣고 게시
- 오프라인에서도 기기에 먼저 저장되고, 연결되면 마지막 수정 시각이 최신인 쪽으로 맞춘다
- 삭제한 메모는 다른 기기에도 전달되도록 내용 없이 `deleted` 표시만 남긴다
- 로그인 안 하면 Firebase를 아예 불러오지 않는다
- 새 도메인에서 쓰려면 Firebase 콘솔 → Authentication → 설정 → 승인된 도메인에 추가

## 휴대폰에 설치

HTTPS 주소가 있어야 설치·오프라인이 됩니다. 가장 쉬운 방법은 GitHub Pages:

1. GitHub에 저장소를 만들고 이 폴더의 파일을 올린다 (`tools/ko_krv_source.json` 제외)
2. 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장
3. 휴대폰 크롬에서 `https://<아이디>.github.io/<저장소>/` 열기 → 메뉴 ⋮ → **홈 화면에 추가 / 앱 설치**

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `index.html`, `css/style.css` | 화면 |
| `js/app.js` | 메모 목록·편집, 말씀 자동 넣기 |
| `js/ref.js` | 구절 표기 인식, 본문 찾기 |
| `js/phrase.js`, `js/search-worker.js` | 문구로 말씀 찾기 (역추적) |
| `js/glossary.js` | 어려운 단어 풀이 사전 |
| `js/ink.js` | 펜 필기 |
| `js/hangul.js` | 한글 자모 풀기 (책 이름 오타 교정) |
| `js/books.js` | 66권 이름·약어 |
| `js/store.js` | 메모 저장 (기기 localStorage) |
| `js/sync.js`, `js/firebase-config.js`, `firestore.rules` | Google 로그인 · 동기화 |
| `sw.js`, `manifest.webmanifest` | 오프라인·설치 (앱 파일을 고치면 `sw.js`의 `VERSION`을 올릴 것) |
| `data/krv.json` | 개역한글 본문 (`tools/build_data.py`로 생성) |
| `tools/make_icons.py` | 아이콘 생성 |
